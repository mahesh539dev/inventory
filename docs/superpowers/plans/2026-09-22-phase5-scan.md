# Phase 5 — Scan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let authenticated staff scan a product's QR code with their
phone camera (or type its SKU manually) and land on that product's
detail page, via a reusable scanner component Phase 6 (Sell) can embed
in its own flow.

**Architecture:** A framework-agnostic `<QrScanner>` client component
wraps `@zxing/browser`'s continuous camera decoder and reports raw
decoded text via an `onDecode` callback, with no knowledge of products
or routing. A pure `parseQrPayload` function interprets that text. A
new auth-gated server action `resolveProductForScan` resolves either a
parsed public identifier or a manually-typed SKU to a product's
internal `id`, reusing existing repository lookups. The `/scan` page
wires all three together and calls `router.push` on a match.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Drizzle
ORM, `@zxing/browser` (new dependency) for camera QR decoding, Vitest
for tests (adding `jsdom` + `@testing-library/react` for the first
component-level test in this project).

**Spec:** [`docs/superpowers/specs/2026-09-22-phase5-scan-design.md`](../specs/2026-09-22-phase5-scan-design.md)

## Global Constraints

- Camera-denied message must read exactly: "Camera access is required
  to scan QR codes. Please enable camera access in your browser
  settings." (source spec section 14/33).
- No-camera-device message: "No camera detected on this device." (this
  plan's own wording — the source spec only specifies the denied-state
  copy verbatim; the no-device case gets a plain equivalent).
- `/scan` must always show the manual-SKU fallback, not only when the
  camera is denied (source spec section 14: "Enter SKU Manually" is
  listed as a standing fallback).
- `resolveProductForScan` requires authentication (`requireUser()`) —
  scanning is not admin-gated (source spec's "Authenticated QR Scan"
  section says "staff logs in," not "admin logs in").
- Use `@zxing/browser` specifically — already decided during
  brainstorming; do not substitute another library mid-implementation.
- Do not modify `/p/[publicIdentifier]` or
  `/api/public/products/[identifier]` (Phase 3, explicitly out of
  scope).
- Archived products must resolve and navigate normally — no new
  status filtering in `resolveProductForScan`.

## Review Focus

- **QR payload from a different/older deployment's URL shape** — a
  sticker printed before some future origin change, or a URL with
  extra query params/trailing slash — must still extract the
  identifier via the path pattern, not fail because of an exact-string
  mismatch. Task 1's parser tests cover trailing slash and query
  params.
- **Camera permission revoked mid-session** (user denies via a browser
  prompt that reappears, or the underlying track ends unexpectedly) —
  the component must not crash or hang in a stale "requesting" state;
  it should transition to the `denied`/`unavailable` message. Task 2
  covers the initial denial path; a `track.onended`-triggered
  transition is explicitly out of scope for this phase (documented
  below) since the spec only requires handling the initial permission
  prompt.
- **Manual SKU submitted with only whitespace** — must be rejected
  client-side before calling the server action, not silently treated
  as a valid non-empty string. Task 4 covers this.
- **Rapid double-decode of the same QR while the camera stays pointed
  at it** — must not fire `resolveProductForScan` twice or double
  `router.push`. Task 2 (component-level repeat-guard) and Task 4
  (page sets `paused` synchronously on first decode) together cover
  this.
- **`resolveProductForScan` called while unauthenticated** (e.g. a
  stale tab after logout, or a direct call bypassing the UI) — must
  reject via `requireUser()`'s redirect, not silently resolve a
  product. Task 3 covers this explicitly.

- [ ] **Step 3: Write the implementation**

A "bare identifier" is any non-empty trimmed string with no `/`, `:`,
or whitespace in it (this app's `publicIdentifier` values are
`nanoid`-generated, so they never contain those characters — see
`lib/services/qr.service.ts`/`lib/db/schema.ts` for how
`publicIdentifier` is generated). Anything containing a `/` is treated
as a URL/path and must match the `/p/<identifier>` shape specifically;
anything else that isn't a clean bare identifier (e.g. the `WIFI:...`
string, which contains no `/` but does contain `:` and `;`) returns
`null`.

```typescript
// lib/scan/parse-qr-payload.ts

const BARE_IDENTIFIER_PATTERN = /^[A-Za-z0-9_-]+$/;

export function parseQrPayload(text: string): { publicIdentifier: string } | null {
  const trimmed = text.trim();
  if (trimmed.length === 0) return null;

  if (trimmed.includes("/")) {
    const match = trimmed.match(/\/p\/([^/?#]+)/);
    return match ? { publicIdentifier: match[1] } : null;
  }

  return BARE_IDENTIFIER_PATTERN.test(trimmed) ? { publicIdentifier: trimmed } : null;
}
```

```typescript
// lib/actions/scan.actions.ts
"use server";

import { requireUser } from "@/lib/auth/guards";
import {
  findProductByPublicIdentifier,
  findProductBySku,
} from "@/lib/repositories/product.repo";

export async function resolveProductForScan(input: {
  publicIdentifier?: string;
  sku?: string;
}): Promise<{ id: string } | null> {
  await requireUser();

  const hasIdentifier = Boolean(input.publicIdentifier);
  const hasSku = Boolean(input.sku);
  if (hasIdentifier === hasSku) {
    throw new Error("resolveProductForScan requires exactly one of publicIdentifier or sku");
  }

  const product = hasIdentifier
    ? await findProductByPublicIdentifier(input.publicIdentifier!)
    : await findProductBySku(input.sku!);

  return product ? { id: product.id } : null;
}
```

Note: this task's test mocks the entire `@zxing/browser` module, so it

```tsx
// components/scan/QrScanner.tsx
"use client";

import { useEffect, useRef, useState } from "react";
import { BrowserQRCodeReader } from "@zxing/browser";

type PermissionState = "requesting" | "granted" | "denied" | "unavailable";

type QrScannerProps = {
  onDecode: (text: string) => void;
  paused?: boolean;
};

export function QrScanner({ onDecode, paused = false }: QrScannerProps) {
  const videoRef = useRef<HTMLVideoElement>(null);
  const lastDecodedRef = useRef<string | null>(null);
  const [state, setState] = useState<PermissionState>("requesting");

  useEffect(() => {
    if (!navigator.mediaDevices?.getUserMedia) {
      setState("unavailable");
      return;
    }

    const reader = new BrowserQRCodeReader();
    let cancelled = false;

    reader
      .decodeFromVideoDevice(undefined as unknown as string, videoRef.current!, (result) => {
        if (cancelled || !result) return;
        const text = result.getText();
        if (text === lastDecodedRef.current) return;
        lastDecodedRef.current = text;
        onDecode(text);
      })
      .then(() => {
        if (!cancelled) setState("granted");
      })
      .catch((error: unknown) => {
        if (cancelled) return;
        if (error instanceof DOMException && error.name === "NotAllowedError") {
          setState("denied");
        } else {
          setState("unavailable");
        }
      });

    return () => {
      cancelled = true;
      BrowserQRCodeReader.releaseAllStreams();
    };
    // eslint-disable-next-line react-hooks/exhaustive-deps -- onDecode identity intentionally excluded; reader is set up once per mount
  }, []);

  useEffect(() => {
    if (!paused) lastDecodedRef.current = null;
  }, [paused]);

  if (state === "denied") {
    return (
      <p role="alert" className="text-sm text-destructive">
        Camera access is required to scan QR codes. Please enable camera
        access in your browser settings.
      </p>
    );
  }

  if (state === "unavailable") {
    return <p role="alert" className="text-sm text-destructive">No camera detected on this device.</p>;
  }

  return (
    <video
      ref={videoRef}
      data-testid="qr-video"
      className="w-full rounded-md border"
      muted
      playsInline
    />
  );
}
```

```tsx
// app/(app)/scan/page.tsx
"use client";

import { useState, useTransition } from "react";
import { useRouter } from "next/navigation";
import { QrScanner } from "@/components/scan/QrScanner";
import { parseQrPayload } from "@/lib/scan/parse-qr-payload";
import { resolveProductForScan } from "@/lib/actions/scan.actions";
import { Input } from "@/components/ui/input";
import { Button } from "@/components/ui/button";
import { Label } from "@/components/ui/label";

const NOT_RECOGNIZED_ERROR = "Not a recognized product QR code";
const NOT_FOUND_ERROR = "Product not found — it may have been removed or its QR code regenerated.";

export default function ScanPage() {
  const router = useRouter();
  const [paused, setPaused] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [sku, setSku] = useState("");
  const [isPending, startTransition] = useTransition();

  function handleResolved(result: { id: string } | null) {
    if (result) {
      router.push(`/products/${result.id}`);
      return;
    }
    setError(NOT_FOUND_ERROR);
    setPaused(false);
  }

  function handleDecode(text: string) {
    const parsed = parseQrPayload(text);
    if (!parsed) {
      setError(NOT_RECOGNIZED_ERROR);
      return;
    }

    setError(null);
    setPaused(true);
    startTransition(async () => {
      const result = await resolveProductForScan({ publicIdentifier: parsed.publicIdentifier });
      handleResolved(result);
    });
  }

  function handleManualSubmit() {
    const trimmed = sku.trim();
    if (trimmed.length === 0) return;

    setError(null);
    startTransition(async () => {
      const result = await resolveProductForScan({ sku: trimmed });
      handleResolved(result);
    });
  }

  return (
    <div className="mx-auto max-w-sm space-y-6 p-6">
      <h1 className="text-xl font-semibold">Scan Product</h1>

      <QrScanner onDecode={handleDecode} paused={paused} />

      {error && (
        <p role="alert" className="text-sm text-destructive">
          {error}
        </p>
      )}

      <div className="space-y-2">
        <Label htmlFor="manual-sku">Or enter SKU manually</Label>
        <div className="flex gap-2">
          <Input
            id="manual-sku"
            value={sku}
            onChange={(event) => setSku(event.target.value)}
            placeholder="SKU"
          />
          <Button type="button" onClick={handleManualSubmit} disabled={isPending}>
            Find Product
          </Button>
        </div>
      </div>
    </div>
  );
}
```
